# Littlebanbrick.github.io

A minimal React website powered by [Vite](https://vitejs.dev) and hosted on [GitHub Pages](https://pages.github.com).

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build and deploy

The site is automatically deployed to GitHub Pages on every push to `main` via GitHub Actions.  
To build manually:

```bash
npm run build
```
